# คู่มือการใช้งานเครื่องมือประเมินคุณภาพแผนการจัดการเรียนรู้ครูอาชีวศึกษา
## (AI Vocational Lesson Plan Evaluator)

ระบบวิเคราะห์และประเมินคุณภาพแผนการจัดการเรียนรู้มุ่งเน้นสมรรถนะตามมาตรฐานสำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.) พ.ศ. 2567

---

### 🌟 คุณสมบัติเด่นของระบบ

1. **แนบไฟล์แล้ววิเคราะห์ทันที (Instant File Analysis)**:
   - รองรับไฟล์เอกสารแผนการสอนทั้ง **PDF**, **Microsoft Word (.docx)** และ **ไฟล์ข้อความ (.txt)**
   - มีโหมดคัดลอกข้อความมาวางโดยตรง (Direct Paste)
2. **ประเมินบนฐานหลักสูตรฐานสมรรถนะ (Competency-Based)**:
   - ตรวจสอบความสอดคล้องของคำอธิบายรายวิชาและสมรรถนะประจำหน่วย
   - วิเคราะห์จุดประสงค์เชิงพฤติกรรม (K-P-A) แจกแจงคำกริยาที่วัดได้จริง พร้อมเกณฑ์เวลาและความแม่นยำ
   - ตรวจสอบกระบวนการสอนสายช่างและสายบริการ เช่น รูปแบบ **MIAP** และ **Project-Based Learning (PBL)**
   - ตรวจสอบความสมบูรณ์ของ **ใบสั่งงาน (Job Sheet)** และ **มาตรการความปลอดภัยในการทำงาน (Safety First) & 5ส**
   - ตรวจสอบเกณฑ์การวัดผลตามสภาพจริง (Authentic Rubrics) และแบบบันทึกหลังสอน
3. **ระบบแนะนำปรับปรุง (AI Coaching & Rewriting)**:
   - ชี้จุดบกพร่อง พร้อมยกตัวอย่างข้อความที่ปรับปรุงแล้วตามมาตรฐานวิชาชีพ
4. **ส่งออกรายงานสรุปผลพร้อมพิมพ์ (Printable Report)**:
   - มีปุ่มพิมพ์รายงานผลการประเมินสรุป 5 มิติ เพื่อใช้ยื่นรายงานฝ่ายวิชาการ หรือแนบประกอบการประเมินวิทยฐานะ ว.PA
5. **ทำงานได้ทันทีแบบ Zero-Setup**:
   - ไม่ต้องติดตั้งโปรแกรม ไม่ต้องลง Python เปิดใช้งานผ่านเว็บเบราว์เซอร์ (Chrome / Edge) ได้ทันที
